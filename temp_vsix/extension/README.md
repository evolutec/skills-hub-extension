# Skills Hub VS Code Extension

Skills Hub est une extension Visual Studio Code pour gérer et visualiser vos agents et leurs compétences (skills) de façon intuitive.

## Fonctionnalités principales
- Ajout et suppression d'agents via une interface moderne.
- Visualisation des skills associés à chaque agent.
- Interface utilisateur épurée et moderne.

## Installation
1. Téléchargez le fichier `.vsix` généré.
2. Dans VS Code, allez dans Extensions > ... > Installer depuis un VSIX...
3. Sélectionnez le fichier `.vsix`.

## Dépannage
Si l'installation échoue, assurez-vous d'utiliser une version récente de VS Code et que le fichier README.md est présent dans le package.
